# Phase 2.3 Tests

## Цель
Проверить работоспособность новых модулей, созданных в рамках рефакторинга extension.ts.

## Как запустить:

1. Простой запуск всех тестов фазы 2.3:
   ```bash
   npm test -- tests/log-service.test.ts --testTimeout=5000
   ```

2. Использование скрипта:
   ```bash
   ./tests/run-phase-2.3-tests.sh
   ```

## Что тестируется:

### 1. LogService (`tests/log-service.test.ts`)
- Форматирование записей логов
- Добавление логов в shared storage и output channel
- Получение логов из памяти
- Очистка логов

### 2. StorageService (тест пока не создан)
- Сохранение порта в файл
- Удаление файлов конфигурации
- Загрузка конфигурации AI Debug

### 3. PromptService (тест пока не создан)
- Копирование промпт-модулей из расширения в рабочую область

### 4. RoleService (тест пока не создан)
- Синхронизация ролей с Roo Code

### 5. HTTP Server (`tests/http-server.test.ts` – существующий тест)
- Проверка работы HTTP сервера

### 6. WebSocket (`tests/websocket.test.ts` – пока нет)
- Проверка работы WebSocket сервера

### 7. UI Bridge (`tests/ui-bridge.test.ts` – пока нет)
- Проверка UI компонентов

## Ожидаемое поведение:
- Каждый тест имеет timeout 5 секунд
- Все тесты должны завершиться успешно
- Общее время выполнения < 30 секунд

## Если тесты проходят:
- Зафиксируйте изменения: `git add -A && git commit -m "feat: phase 2.3 модульная архитектура"`
- Запушьте: `git push`

## Если тесты не проходят:
- Проверьте сообщения об ошибках
- Убедитесь, что все зависимости импортированы корректно
- Проверьте, что новые модули правильно экспортируют классы
- Запустите тесты по одному для диагностики

## Примечания:
- Рефакторинг extension.ts ещё не завершён полностью (цель <150 строк не достигнута)
- Созданы только сервисы, команды, HTTP сервер, WebSocket и UI bridge ещё не вынесены
- Данные тесты проверяют базовую функциональность новых модулей
