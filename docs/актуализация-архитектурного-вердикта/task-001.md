# Задача 001: Проверить статус Race Condition в File Lock

## Что нужно проверить

Проверить файл [`src/async-lock.ts`](../../src/async-lock.ts) на наличие исправления Race Condition.

**Конкретные проверки:**
1. Метод `processQueue()` устанавливает флаг `locked = true` ДО запуска операции
2. Флаг `locked` остается `true` до вызова `release()`
3. Используется класс `AsyncMutex` с атомарными операциями
4. Нет возможности одновременного выполнения операций

## Как протестировать

### Тест 1: Параллельное выполнение операций
```bash
# Создать тестовый файл tests/async-lock-race-condition.test.ts
# Запустить тест
npm test -- tests/async-lock-race-condition.test.ts
```

### Тест 2: Стресс-тест с множественными операциями
```bash
# Запустить тест с 1000 параллельных операций
node -e "
const lock = require('./src/async-lock.ts');
// Запустить 1000 параллельных операций
// Проверить что операции выполняются последовательно
"
```

**Лимит:** Макс. 100 строк лога или 30 секунд выполнения

**Ожидаемый результат:** Все операции выполняются последовательно, без interleaving
