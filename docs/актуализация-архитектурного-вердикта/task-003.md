# Задача 003: Проверить статус утечки памяти в SharedLogStorage

## Что нужно проверить

Проверить файл [`src/shared-log-storage.ts`](../../src/shared-log-storage.ts) на наличие исправления утечки памяти.

**Конкретные проверки:**
1. Метод `stopWatcher()` существует и очищает debounce таймер
2. Метод `stopWatcher()` закрывает `fs.watch` хэндл
3. Метод `dispose()` полностью очищает все ресурсы
4. Нет оставшихся ссылок на ресурсы после вызова `dispose()`

## Как протестировать

### Тест 1: Проверка очистки ресурсов
```bash
# Запустить тест
npm test -- tests/shared-log-storage-dispose.test.ts
```

### Тест 2: Мониторинг памяти
```bash
# Запустить с профилированием памяти
node --inspect tests/shared-log-storage-memory-leak.test.ts
# Проверить что память освобождается после dispose()
```

**Лимит:** Макс. 100 строк лога или 30 секунд выполнения

**Ожидаемый результат:** Все ресурсы освобождены, память не растет после dispose()
