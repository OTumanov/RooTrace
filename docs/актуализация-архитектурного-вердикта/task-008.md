# Задача 008: Проверить статус валидации входных данных

## Что нужно проверить

Проверить файл [`src/role-manager.ts`](../../src/role-manager.ts) на наличие исправления валидации входных данных.

**Конкретные проверки:**
1. Метод `loadCustomInstructions()` содержит константу `MAX_INSTRUCTION_SIZE`
2. Метод `loadCustomInstructions()` содержит константу `WARN_THRESHOLD`
3. Есть проверка размера промпта
4. Есть обрезка при превышении лимита
5. Есть предупреждение пользователю

## Как протестировать

### Тест 1: Проверка валидации с большим промптом
```bash
# Запустить тест
node -e "
const { RoleManager } = require('./src/role-manager.ts');
// Создать промпт размером > MAX_INSTRUCTION_SIZE
// Проверить что промпт обрезается
// Проверить что выводится предупреждение
"
```

### Тест 2: Проверка порога предупреждения
```bash
# Запустить тест
node -e "
const { RoleManager } = require('./src/role-manager.ts');
// Создать промпт размером > WARN_THRESHOLD
// Проверить что выводится предупреждение
"
```

**Лимит:** Макс. 100 строк лога или 30 секунд выполнения

**Ожидаемый результат:** Промпт обрезается при превышении лимита, предупреждение выводится
