# Задача 007: Проверить статус синхронизации между HTTP и MCP

## Что нужно проверить

Проверить файл [`src/versioned-logs.ts`](../../src/versioned-logs.ts) на наличие исправления синхронизации.

**Конкретные проверки:**
1. Реализован полный MVCC паттерн
2. Интерфейс `VersionedLogs` содержит version, timestamp, hash
3. Метод `mergeLogs()` с валидацией хеша
4. Метод `mergeLogs()` с разрешением конфликтов

## Как протестировать

### Тест 1: Проверка MVCC паттерна
```bash
# Запустить тест
npm test -- tests/versioned-logs-mvcc.test.ts
```

### Тест 2: Проверка разрешения конфликтов
```bash
# Запустить тест
npm test -- tests/versioned-logs-merge-async.test.ts
```

**Лимит:** Макс. 100 строк лога или 30 секунд выполнения

**Ожидаемый результат:** MVCC паттерн работает, конфликты разрешаются корректно
