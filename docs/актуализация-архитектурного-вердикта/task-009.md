# Задача 009: Проверить статус O(n) priority queue

## Что нужно проверить

Проверить файл [`src/message-queue.ts`](../../src/message-queue.ts) на наличие исправления O(n) priority queue.

**Конкретные проверки:**
1. Реализована простая FIFO очередь
2. Enqueue (push) имеет сложность O(1)
3. Dequeue (shift) имеет сложность O(1)
4. Нет операций `findIndex` и `splice`
5. Приоритеты убраны

## Как протестировать

### Тест 1: Проверка сложности операций
```bash
# Запустить тест
npm test -- tests/message-queue-performance.test.ts
```

### Тест 2: Стресс-тест с множественными операциями
```bash
# Запустить тест с 10000 операций
node -e "
const { MessageQueue } = require('./src/message-queue.ts');
// Добавить 10000 сообщений
// Извлечь 10000 сообщений
// Замерить время выполнения
"
```

**Лимит:** Макс. 100 строк лога или 30 секунд выполнения

**Ожидаемый результат:** O(1) сложность для enqueue и dequeue, нет O(n) операций
