# Настройка шифрования в RooTrace

## Обзор

RooTrace использует шифрование для защиты чувствительных данных (конфигурации, логов, сессий). Перед использованием расширения необходимо настроить ключ шифрования.

## Способы настройки

### Способ 1: Использование ROO_TRACE_ENCRYPTION_KEY (рекомендуется)

Этот способ использует готовый 32-байтный ключ в hex-формате.

#### Генерация ключа

**macOS/Linux:**
```bash
# Генерация случайного 32-байтного ключа в hex-формате
openssl rand -hex 32
```

**Windows (PowerShell):**
```powershell
# Генерация случайного 32-байтного ключа в hex-формате
(New-Object Security.Cryptography.RNGCryptoServiceProvider).GetBytes(32) | ForEach-Object { $_.ToString("x2") } | Out-String
```

#### Настройка в VS Code

1. Откройте настройки VS Code (Cmd+, или Ctrl+,)
2. Найдите "Terminal > Env: Linux/Mac/Windows" в зависимости от вашей ОС
3. Добавьте переменную окружения:
   ```
   ROO_TRACE_ENCRYPTION_KEY=<ваш_ключ_в_hex_формате>
   ```

#### Настройка в .env файле

Создайте файл `.env` в корне вашего проекта:
```
ROO_TRACE_ENCRYPTION_KEY=<ваш_ключ_в_hex_формате>
```

### Способ 2: Использование ROO_TRACE_SECRET_PHRASE

Этот способ использует секретную фразу, которая будет преобразована в ключ с помощью алгоритма scrypt.

#### Требования к секретной фразе

- Минимум 12 символов
- Не должна быть равна 'roo-trace-default-secret'
- Рекомендуется использовать случайную строку с высокой энтропией

#### Примеры безопасных фраз

```
# Пример 1: случайная строка
Xk9#mP2$vL5@nQ8!

# Пример 2: длинная мнемоническая фраза
purple-elephant-dancing-midnight-clouds-quantum-leap

# Пример 3: комбинация слов и символов
OceanWave99@SunsetBeach#MountainPeak
```

#### Настройка в VS Code

1. Откройте настройки VS Code (Cmd+, или Ctrl+,)
2. Найдите "Terminal > Env: Linux/Mac/Windows"
3. Добавьте переменную окружения:
   ```
   ROO_TRACE_SECRET_PHRASE=<ваша_секретная_фраза>
   ```

#### Настройка в .env файле

Создайте файл `.env` в корне вашего проекта:
```
ROO_TRACE_SECRET_PHRASE=<ваша_секретная_фраза>
```

## Проверка конфигурации

После настройки ключа шифрования перезапустите VS Code. Если конфигурация верна, расширение активируется без ошибок.

## Миграция с дефолтного ключа

Если вы ранее использовали расширение с дефолтным ключом, зашифрованные данные будут недоступны после изменения ключа. Для миграции:

1. Экспортируйте важные данные через команды экспорта (JSON, CSV, Markdown)
2. Настройте новый ключ шифрования
3. Расширение создаст новые зашифрованные файлы с новым ключом

## Безопасность

- Никогда не коммитьте `.env` файл с ключами шифрования
- Используйте разные ключи для разных окружений (dev, staging, prod)
- Регулярно меняйте ключи шифрования в продакшене
- Храните ключи в безопасном месте (менеджеры паролей, секреты CI/CD)
