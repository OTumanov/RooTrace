## 🚀 RooTrace v0.0.1: AI-Driven Debugging Unleashed

**RooTrace** — мост между вашим кодом и мозгом ИИ. Мы внедрили архитектуру **MCP (Model Context Protocol)** и **Железный мост** — систему безотказной файловой синхронизации, чтобы сделать отладку не просто быстрой, а интеллектуальной и надежной.

### 🌟 Что нового:

#### Кастомные инструкции и правила (Custom Rules Loading)
- **Lazy Loading**: Правила загружаются по требованию через `load_rule` инструмент
- **Поддержка файлов**: Автоматическое чтение `.roo/rules/` и `.roo/rules-{mode}/` для специализированных инструкций
- **Модульная архитектура**: MCP Handler и Code Injector разбиты на специализированные модули для удобства разработки
- **Защита от зацикливания**: Встроенная защита от повторяющихся действий через мониторинг аномалий

#### Интеграция диагностики VS Code
- **Автоматическое обнаружение ошибок**: Интеграция с панелью Problems через `get_problems`
- **Pre-Flight Check**: Проверка диагностики перед началом работы (Phase 0.4)
- **Проверка после изменений**: Автоматическая проверка линтера после каждой вставки проб или исправления кода
- **Fallback на @problems**: Поддержка упоминания `@problems` если MCP tool недоступен

#### Защита от отравления контекста
- **Валидация данных**: Проверка всех входящих и исходящих данных на control characters и подозрительные паттерны
- **Детекция аномалий**: Обнаружение повторяющихся ответов, галлюцинаций, злоупотребления инструментами
- **Автоматический сброс**: Автоматический сброс сессии при превышении порога аномалий (настраиваемый)
- **Мониторинг качества**: Отслеживание состояния сессии, подсчет аномалий, логирование инцидентов

#### Мета-когнитивное управление и правила гигиены кода
- **Экспертная панель**: Аналитик, Критик, Изобретатель, Профессор, Скептик — внутренний диалог перед каждым изменением кода
- **The 5-Line Rule**: Пробы максимум 5-7 строк для чистоты кода
- **Метрики количества**: Автоматический сбор `len(array)` и флагов `is_empty` для диагностики
- **Оптимизация импортов**: Не дублирует `json` если уже импортирован в файле
- **Контроль галлюцинаций**: Профессор следит за правильной терминологией (русские термины при русском языке)
- **ADHD-специфика**: Краткие TODO list (макс. 5-7 слов на задачу) для легкого сканирования
- **Английские промпты**: Система использует английские промпты для экономии токенов и лучшего следования инструкциям

#### Железный мост — безотказная синхронизация
- **Файловые блокировки**: Все операции с файлами защищены через `withFileLock` — исключены race conditions
- **Режим Observer**: `fs.watchFile` отслеживает изменения файла логов в реальном времени (интервал 200 мс, debounce 100 мс)
- **Гибридный контекст**: Extension (Writer) и MCP (Reader) работают через единый файл `.rootrace/ai_debug_logs.json`
- **Zero-Latency**: MCP видит изменения быстрее, чем вы успеете переключить вкладку
- **Директория .rootrace**: Все файлы конфигурации и логов хранятся в `.rootrace/` (автоматически добавлена в `.gitignore`)

#### Улучшенная инъекция проб
- **Модульная архитектура**: Code Injector разбит на специализированные модули (генераторы проб для 12 языков, валидаторы, позиционирование, host detection для Docker)
- **UUID-маркеры**: Каждая проба получает уникальный ID (`a1b2`) для точного удаления
- **Автоматический Rollback**: При ошибках синтаксиса файл автоматически откатывается к исходному состоянию
- **Хирургическая очистка**: Регулярные выражения находят и удаляют блоки проб даже если код вокруг изменен
- **Безопасность**: Проверка синтаксиса для 12 языков программирования перед фиксацией изменений
- **Docker поддержка**: Автоматическое определение Docker окружения для Python и Go проектов с настройкой правильного хоста (`host.docker.internal` на Mac/Windows, `172.17.0.1` на Linux)
- **Code Hygiene**: Zero-dependency injections (с использованием стандартных библиотек и системных инструментов для каждого языка), metadata abstraction, асинхронность, метрики количества
- **Мета-когнитивная проверка**: Внутренний диалог перед каждым изменением кода для предотвращения ошибок компиляции
- **Расширяемость**: Легко добавлять поддержку новых языков через фабрики генераторов и валидаторов

#### Full MCP Integration
- **Zero-Configuration**: Расширение само находит Roo Code и регистрирует сервер. Тебе не нужно править конфиги руками.
- **Scientific Debugging Workflow**: Реализован цикл "Гипотеза -> Инъекция -> Анализ -> Очистка".
- **Hybrid Logging**: Прием логов по HTTP и передача их ИИ через защищенный STDIO канал.
- **Automatic Cleanup**: Больше никаких забытых `console.log` в коде — система вычищает за собой всё.
- **Security**: Система одобрения для чтения логов (требует нажатия кнопки пользователем).
- **Python Safety**: Для Python файлов используется Block Rewrite (`apply_diff`) вместо точечной инъекции.
- **Dynamic Network Discovery**: Автоматическое обнаружение порта из `.debug_port` и Docker bridge (`host.docker.internal` или `172.17.0.1`)
- **Smoke Test (Phase 2.2)**: Обязательная проверка соединения реальным тестовым логом перед началом инструментации
- **Custom Instructions**: Поддержка загрузки правил из `.roo/rules/` и `.roo/rules-{mode}/` с lazy loading
- **Context Protection**: Встроенная защита от отравления контекста с автоматическим сбросом сессии

### 🛠 Как начать:

1. Установите `.vsix` расширения.
2. Откройте проект и запустите Roo Code (Cline).
3. Используйте роль **AI Debugger** для автоматической отладки.

### 🔒 Надежность и безопасность

- **Файловые блокировки**: Исключены race conditions при одновременной записи и чтении
- **Автоматический Rollback**: Файлы автоматически откатываются при ошибках синтаксиса
- **UUID-маркеры**: Точное удаление только вставленных проб, без влияния на пользовательский код
- **Валидация путей**: Защита от path traversal атак
- **Синхронизация**: Гарантированная консистентность данных между Extension и MCP
- **Резервные копии**: Требование создания git commit или .bak копии перед редактированием файлов
- **Система одобрения**: Чтение логов требует явного одобрения пользователя через кнопку в UI
- **Python защита**: Для Python файлов используется Block Rewrite через `apply_diff` (запрет точечной инъекции для безопасности)
- **Docker автоматизация**: Автоматическое определение Docker окружения, настройка хоста через `_rootrace_host` (Python) или `rootraceHost` (Go) с поддержкой Linux, Mac, Windows сценариев
- **Защита от отравления контекста**: Валидация всех данных, детекция аномалий, автоматический сброс при превышении порога
- **Защита от зацикливания**: Встроенная детекция повторяющихся действий и бесконечных циклов
- **Валидация диагностики**: Автоматическая проверка линтера после каждого изменения кода

### 🎯 Ключевые особенности

- **Безотказность**: Система работает на уровне файловой системы, даже если VS Code зависнет
- **Чистота кода**: После отладки в коде не остается забытых `console.log` или закомментированных кусков
- **Скорость**: Низкая латентность благодаря `fs.watchFile` и файловым блокировкам
- **Надежность**: Инструмент работает как терминатор — пришел, увидел (логи), почистил за собой
- **Docker поддержка**: Автоматическое определение Docker окружения и настройка правильного хоста для Python и Go
- **Мультиязычность**: Поддержка JavaScript/TypeScript, Python, Java, Go, Rust, C++, PHP, Ruby, C#, Swift, Kotlin (12 языков с полной поддержкой код-генерации)
